# 修辞数据资源

本文件夹包含所需的数据集。

## 目录结构

修辞数据资源/
├── 平行语料/
│   └── 平行语料数据.json
└── 识别/
    └── 修辞识别数据.json

## 数据说明

### 平行语料数据 (`平行语料/平行语料数据.json`)

**数据格式**：
```json
{
  "修辞类型": [
    ["修辞句", "平实句"],
    ["修辞句", "平实句"],
    ...
  ]
}
```

**字段说明**：
| 字段 | 说明 |
|------|------|
| 修辞类型 | 如"自释"、"比喻"等修辞格名称 |
| 修辞句 | 包含该修辞手法的原始句子 |
| 平实句 | 去除修辞手法后的直白表达 |

---

### 修辞识别数据 (`识别/修辞识别数据.json`)

**数据格式**：
```json
{
  "修辞类型": [
    "包含该修辞的句子1",
    "包含该修辞的句子2",
    ...
  ]
}
```

**字段说明**：
| 字段 | 说明 |
|------|------|
| 修辞类型 | 如"设问"、"摹绘"等修辞格名称 |
| 句子列表 | 包含该修辞手法的例句集合 |
